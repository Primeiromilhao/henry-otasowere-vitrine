# Vitrine Henry Otasowere

Vitrine audiovisual do Profeta Henry Otasowere / Voz da Cura Network.

## Fonte oficial
- YouTube: https://www.youtube.com/@Vozdacura
- Catálogo atual: 368 vídeos
- Cada cartão usa o URL individual do vídeo.

## Estrutura
- index.html — interface
- style.css — estética premium
- app.js — filtros e catálogo
- videos.json — catálogo
- assets/ — imagens da vitrine
- .github/workflows/pages.yml — publicação automática no GitHub Pages

A imagem principal é preparada no servidor de build do GitHub Pages para reduzir dependências no computador local.
